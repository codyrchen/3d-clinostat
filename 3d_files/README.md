# 3D print files

Put your `.3mf` / `.stl` files here.

If you printed the upstream parts unmodified, it's cleaner to link to
[OpenClino's `3d_files/`](https://github.com/wahabk/Clinostat/tree/main/3d_files) rather than
re-host them — that way people get the maintained version. Commit files here for parts you
modified or designed yourself.
