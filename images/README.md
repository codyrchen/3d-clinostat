# Images

Photos and video of the build. Nothing here yet — the build hasn't been photographed.

The top-level README expects `hero.jpg`; the rest are referenced from the docs as they're added.

| File | What it should show |
|---|---|
| `hero.jpg` | The assembled machine, well lit, plain background |
| `wiring.jpg` | The electronics, referenced from `hardware/README.md` |
| `running.gif` / `running.mp4` | It actually rotating |
| `sample.jpg` | A sample loaded in the chamber |

Upstream's CAD renders, circuit diagrams, and step-by-step build photos are **not** copied here — see
[OpenClino's `docs/images/`](https://github.com/wahabk/Clinostat/tree/main/docs/images). They're
around 34 MB, mostly two animated GIFs, so this repo links to them rather than duplicating them.

> Note: `.gitignore` has commented-out rules for `*.mp4` / `*.mov`. Uncomment them if you'd rather
> host video elsewhere than commit it.
